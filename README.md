## 🚀 Project: Secure AWS Website Deployment

**Live Site:** https://oshali-cloud.duckdns.org

### 📋 Project Overview
Deployed a production-grade HTTPS website on AWS EC2 Ubuntu Linux using complete DevOps workflow from Day 1 to Day 4.

### 🛠️ Tech Stack
- **Cloud:** AWS EC2, Security Groups
- **OS:** Ubuntu Linux 22.04 LTS
- **Web Server:** Nginx
- **Domain & DNS:** DuckDNS
- **Security:** Let's Encrypt SSL, Certbot, UFW Firewall
- **Tools:** Git, GitHub, VS Code Remote SSH, Bash

### ⚡ 4-Day Journey
**Day 1:** Launched AWS EC2 Ubuntu instance, SSH setup, Linux basics, Git & VS Code config
**Day 2:** Installed Nginx, deployed HTML website, Git push to GitHub
**Day 3:** Configured custom domain with DuckDNS, DNS A Record, Nginx server blocks
**Day 4:** Implemented Let's Encrypt SSL, HTTPS redirect, Certbot auto-renewal via cron
